# שפה · כיתה ה׳ (Kita)

אתר שנתי לשפה בכיתה ה׳, לבקשתה של מור לנגר אפל. בעקבות ספרי ״עולמות״ (מט״ח) ותוכנית הלימודים של משרד החינוך.

- 6 פרקים, 33 שבועות, 231 שיעורים (42 דפי שיעור בפרק 1, ו-27 דפי שבוע עם 7 שיעורים בכל אחד)
- 17 משחקים דיגיטליים, 7 משחקים להדפסה, 75 בחנים, 22 סרטונים
- הקראה (Web Speech, he-IL), חיפוש וסינון, ימי שיא, מעגל השנה, מסלול שטף, אזור מורים

אתר סטטי (HTML/CSS/JS), נבנה עם `build/make_site.py`. אין איסוף מידע על תלמידים.
